## 2. Reglas WHS (Rules of Handicapping 2024)

- **3.1a** sin índice: tope par + 5 (`TOPE_SIN_INDICE_SOBRE_PAR`). **3.1b** con índice: par + 2 + golpes recibidos (`maximoPorHoyo`, `src/golf/core/ajuste-whs.ts:41`). Plus devuelve golpe → par + 1 en esos hoyos (`strokesRecibidosEnHoyo` devuelve −1, `stableford-score.ts:115-121`).
- **6.1a** CH = HI × Slope/113 + (CR − Par) con el HI vigente el día de la ronda; **6.1b** 9h (`resolverCourseHandicap`, `course-handicap.ts:78-100`). Golpes del tope = Course Handicap, nunca playing handicap.
- **Apéndice E** reparto por SI, CH > 18 da vueltas. SI permutación 1..N sobre hoyos jugados: `normalizedStrokeIndexByHole(holes, N, hoyos)` (`stroke-index.ts:225`).
- **2.2a** mínimo de hoyos (`alcanzaMinimoDeHoyosJugados`). Hoyos estimados ya llegan topados; re-topar es idempotente.
- Fallbacks (decisión documentada, nunca inventa): hoyo sin par → no se topa, `completo:false`; SI no confiable → tope holgado `par + 2 + ceil(CH/N)` (el índice nunca sale más bajo que el oficial).
- Índice = `profiles.indice`; si null → `profiles.indice_golfers`; ambos null → 3.1a. Decisión CTO: un `indice_golfers` cuenta como índice establecido (anotado).

## 3. Diseño

Canónica en `src/golf/core/ajuste-whs.ts`:

```ts
export type FuenteSI = 'catalogo' | 'front_asumido' | 'desconocido'
export interface GrossAjustadoInput {
  scores: Record<string | number, number | null | undefined>  // por número REAL de hoyo
  hoyos: readonly number[]
  parPorHoyo: Record<number, number | null | undefined>
  siPorHoyo: Record<number, number> | null   // normalizado 1..N; null → tope holgado
  courseHcp: number | null                   // para ESTOS hoyos (9h → CH de 9); null → 3.1a
}
export interface GrossAjustadoResult {
  grossBruto: number; grossAjustado: number
  hoyosTopados: Array<{ hoyo: number; gross: number; tope: number }>
  hoyosSinPar: number[]; completo: boolean
}
export function topeHolgado(par: number, courseHcp: number | null, totalHoyos: number): number
export function grossAjustadoWHS(input: GrossAjustadoInput): GrossAjustadoResult
```

Solo scores ≥ 1 cuentan; `golpes = courseHcp == null ? null : strokesRecibidosEnHoyo(courseHcp, si, hoyos.length)`; tope = `maximoPorHoyo(par, golpes)` o `topeHolgado` si `siPorHoyo` es null.

`diferencialDeTarjeta` (`src/lib/indice-golfers.ts:116`): renombrar `totalGross` → `grossAjustado` (rompe en compile a todo caller: intencional). `calcularDiferencial` queda fórmula pura `@internal`; callers directos (`docs/REORDENAMIENTO_TRACKING.md:784-793`) migran.

Capa de datos `src/lib/data/ajuste-whs-fila.ts`:

